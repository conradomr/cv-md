Fontes e decisões de design

Os temas foram desenhados para que recrutadores e sistemas de candidatura encontrem as informações em uma sequência clara. Aqui estão os critérios, escolhas visuais e fontes que orientaram cada modelo.

As referências consultadas favorecem formatos simples para currículos enviados por plataformas. Os modelos seguem essa orientação com uma coluna, fontes comuns e tons neutros; o Editorial oferece uma alternativa tipográfica para áreas que valorizam esse estilo.

Estrutura e ordem nos PDFs

  1. Nome
  2. Área ou cargo
  3. Contato
  4. Resumo opcional
  5. Seções do Markdown
  • Uma coluna; texto e listas reais no PDF, sem tabelas, barras laterais, caixas de texto, gráficos, fotos, logotipos ou ícones que substituam palavras.
  • O nome e os contatos ficam no fluxo normal da página, não em cabeçalhos ou rodapés de impressão. Links de contato também mostram o endereço em texto.
  • As seções são impressas na ordem do Markdown. Para experiência, o padrão recomendado é mais recente primeiro; cada item segue Cargo — Empresa (período), depois os tópicos de resultado.
  • Papel A4 branco; texto de corpo e metadados a partir de 10 pt; fontes comuns (Arial; Georgia no Editorial); margens internas de 13–18 mm, aproximadamente 0,5–0,7 pol.
  • As cores são apenas tons neutros de alto contraste; nenhuma informação depende da cor. A interface do site é escura, mas não é impressa no currículo.
  • Não impomos uma página: experiências adicionais fluem para páginas seguintes sem reduzir a fonte. O PDF permanece selecionável e pesquisável.
  • A exportação Word usa uma versão neutra de uma coluna, com Arial e a mesma ordem de conteúdo; o tema escolhido define o visual de PDF e HTML.

Tipografia, margens e paleta de cada tema

As miniaturas do seletor são desenhos da interface; não fazem parte dos PDFs. Nenhum tema insere foto ou outra imagem. O campo photo é rejeitado para evitar que uma foto pareça ter sido incluída quando não será exportada.

Como aproveitar melhor os temas

  • Para um visual mais tradicional, escolha Clássico; para uma apresentação contemporânea, Moderno; para bastante conteúdo, Compacto; para comunicação e design, Editorial; para áreas técnicas, Técnico.
  • Confira o formato de arquivo indicado pela vaga. O aplicativo oferece PDF, Word (.docx), HTML e JSON Resume; o Markdown (.md) fica como cópia editável do conteúdo.
  • Personalize a ordem das seções e os termos do currículo para destacar a experiência mais relevante para cada oportunidade.
  • Plataformas de candidatura podem ter instruções próprias; use os requisitos do empregador como referência final.
