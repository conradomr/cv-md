# cv-md

Gera currículo a partir de Markdown. Exporta para diversos formatos de arquivos, incluindo PDF e Word. 

## Por que usar?

1. **Gratuito.** Sem custo, sem assinatura, sem marca d'água. Nunca mais pague para fazer um currículo.
2. **Qualidade.** Usa as melhores e mais confiáveis referências do mundo sobre como fazer currículos profissionais (UC Berkeley, MIT, Greenhouse). Pensado milimetricamente, de forma artesanal.
3. **Markdown-based.** Facilita atualizar o currículo: um arquivo fonte, versionável, editável em qualquer editor. Sem lock-in.
4. **Privativo.** Ninguém vê seus dados. O site é estático, sem backend.
5. **Sem brasileirismos.** Vai contra as práticas comuns no mercado local: foto, excesso de informação, temas arbitrários.
6. **Funciona para vaga no exterior.** Segue padrões internacionais de currículo. ATS-friendly.
7. **Na internet.** Não precisa baixar nada para usar. Disponível publicamente.
8. **Offline.** Funciona até sem internet após a primeira visita.

## Stack

- HTML, CSS e JavaScript puro (sem framework)
- CodeMirror (editor Markdown)
- docx (exportação Word)
- JSZip (exportação ZIP)
- Geist (fontes locais)
- Service Worker (cache/offline)
- GitHub Pages (hospedagem)

## Como usar

1. Acesse o site.
2. Escreva seu currículo em Markdown (ou use o modo guiado).
3. Veja a prévia em folhas A4.
4. Exporte: PDF (impressão do navegador), Word, HTML, JSON Resume, ZIP (cinco temas) ou `.md`.
